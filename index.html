03 / 模型可靠性工具2026.07 — 2026.09

MedAudit

医学图像分类模型的数据与特征审计工具。

把可靠性检查做成可复用工具。通过配置驱动的 Python CLI，检查属性可预测性、跨集合近重复和患者分组泄漏；配套评估指标与 Bootstrap 置信区间计算。

工具能回答什么
输入包括冻结特征、样本清单和 JSON 配置；实现总体／类内属性探针，以及 AUROC、Brier、ECE 和患者簇 Bootstrap 指标函数。属性能否从特征中预测，与分类器是否实际依赖该属性，是不同问题。工具区分用户提供的划分与自行生成的划分，并明确无法判断的情形。校准指标函数已实现，完整校准审计尚未接入 CLI。

配套英文运行指南与可运行合成算例：演示校准指标计算，以及固定敏感度、特异度时患病率变化对阳性预测值的影响。算例用于教学，不代表临床性能。

04 / 影像组学研究2026.07 — 至今

HCC-MVI 多期 CT 影像组学

肝细胞癌微血管侵犯预测的方法重建与数据分析。

多期影像与组学特征处理。重建四期 CT、肿瘤／瘤周 VOI 及 94 项原始特征的处理流程，完成 6,660 个 VOI 的重算核对，覆盖有效特征一致性及失败记录复现，并开展去重敏感性分析。

研究现状
研究涉及 111 条历史队列记录；6,660 个 VOI 的核对包含有明确失败记录的项目，不等于全部产生有效特征。现有评估不足以确认模型有效性。保留方法重建偏差、重复扫描处理及不确定性分析，后续结论需要新的验证证据。患者数据与内部研究材料不在本页提供下载。
